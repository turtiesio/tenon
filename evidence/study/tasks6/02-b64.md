# Task 02: b64 (Base64 encoder and decoder)

## Goal

Write a command-line filter that encodes stdin as Base64 (RFC 4648, the
standard alphabet with `=` padding) and wraps the encoded text into lines of
a given width, or, with `-d`, decodes Base64 text back into bytes. Decoding
is strict: anything that is not canonical Base64 (apart from line breaks) is
rejected, and nothing is written in that case.

## Interface

```
b64 [-d] [-w N]
```

- **Arguments** are examined left to right. Options may appear in any order
  and may repeat (for `-w`, the last value wins).
  - `-d`: decode instead of encode.
  - `-w N`: the line width for encoding. The value is the **next** argument
    and must match `[0-9]{1,4}` (leading zeros allowed). Default `76`. `0`
    means no wrapping. With `-d` the width is checked but has no effect.
- **Usage errors (exit 2).** Any other argument (including file names, `--`
  and combined forms such as `-dw`), `-w` without a following argument, or a
  malformed width. Print a message to stderr, print **nothing** on stdout,
  and do not read stdin.
- **stdin.** Read as bytes, at most 1000000 bytes. When encoding, any bytes
  are allowed.
- **stdout.** The encoded text or the decoded bytes.
- **Exit codes.** `0` success, `1` invalid input when decoding, `2` usage
  error.

## Rules

1. **Alphabet.** The 64 characters are `A`-`Z` (values 0-25), `a`-`z`
   (26-51), `0`-`9` (52-61), `+` (62) and `/` (63).
2. **Encoding.** Take the input in groups of 3 bytes (24 bits, first byte in
   the high bits) and write each group as 4 characters of 6 bits each, high
   bits first. If the last group has only 1 byte, pad it with zero bits to 12
   bits, write 2 characters and then `==`. If it has 2 bytes, pad it with
   zero bits to 18 bits, write 3 characters and then `=`.
3. **Wrapping.** Split the encoded text into lines of exactly N characters;
   the last line may be shorter. Every line, including the last, ends with
   `\n`. With N = `0` the whole encoded text is one line followed by `\n`.
   Empty input gives **empty** output (no newline).
4. **Decoding.** First remove every `\n` and `\r` byte from the input,
   wherever they are. The rest must be valid:
   - its length is a multiple of 4 (zero is allowed: the output is then
     empty);
   - it contains only alphabet characters and `=`;
   - `=` appears only at the end, as `=` or `==` closing the **last** group
     of 4 (so `x===`, `==` in the middle, or a group after a padded group are
     invalid);
   - the unused bits are zero: in a group ending with `==`, the low 4 bits of
     the second character's value are 0; in a group ending with a single
     `=`, the low 2 bits of the third character's value are 0.
   A valid text is decoded by reversing rule 2: each group of 4 characters
   gives 3 bytes, a group ending with `=` gives 2 bytes, a group ending with
   `==` gives 1 byte.
5. **Invalid input.** If the text is not valid, print a message to stderr,
   print **nothing** on stdout (not even the bytes of earlier valid groups),
   and exit `1`.

## Examples

In `cmd`, arguments are separated by spaces. In stdout blocks, each line
shown ends with `\n`.

### Example 1: encoding and wrapping

stdin for both runs is the 28 bytes `Many hands make light work.\n`.

cmd: `b64` gives stdout:
```
TWFueSBoYW5kcyBtYWtlIGxpZ2h0IHdvcmsuCg==
```
exit: `0`

cmd: `b64 -w 16` gives stdout:
```
TWFueSBoYW5kcyBt
YWtlIGxpZ2h0IHdv
cmsuCg==
```
exit: `0`

### Example 2: padding and binary input

- cmd: `b64` with stdin `a` gives stdout `YQ==\n` and exit `0`.
- cmd: `b64 -w 0` with stdin `ab` gives stdout `YWI=\n` and exit `0`.
- cmd: `b64` with stdin the three bytes 0x00 0xFF 0xFE gives stdout
  `AP/+\n` and exit `0`.
- cmd: `b64` with empty stdin gives stdout (empty) and exit `0`.

### Example 3: decoding

- cmd: `b64 -d` with stdin `TWFu\r\nIGhh\nbmRz\n` gives stdout `Man hands`
  (9 bytes, no newline) and exit `0`.
- cmd: `b64 -d -w 5` with stdin `QUI=` gives stdout `AB` and exit `0`.
- cmd: `b64 -d` with stdin `QUJD` gives stdout `ABC` and exit `0`.

### Example 4: invalid Base64

Each of these, with cmd `b64 -d`, gives stdout (empty) and exit `1`:

- stdin `QR==` (the low 4 bits of `R`, value 17, are not zero)
- stdin `QQ=` (length 3)
- stdin `Q===` (three padding characters)
- stdin `QQ==QQ==` (a group after a padded group)
- stdin `QU I=` (a space is not allowed)

### Example 5: usage errors

Each of these gives stdout (empty) and exit `2`:

- cmd: `b64 -w`
- cmd: `b64 -w -1`
- cmd: `b64 -dw 4`
- cmd: `b64 input.bin`

## Not required

- The URL-safe alphabet, ignoring garbage characters, or decoding without
  padding.
- Reading from or writing to files given as arguments.
- Any particular stderr wording.
